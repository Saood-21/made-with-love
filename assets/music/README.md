# Music Folder

Place your background music file here.

## File Name
Name your music file: `background-music.mp3`

## Supported Formats
- MP3 (recommended)
- OGG
- WAV

## Recommendations
- Keep file size under 10MB
- Use MP3 format for best browser compatibility
- 128kbps quality is sufficient for background music
- Song duration: 3-5 minutes works great (it will loop)

## How to Add Your Music

1. Find or create your music file
2. Name it `background-music.mp3`
3. Upload it to this folder
4. That's it! The music will automatically work on all pages

## Copyright Notice
Make sure you have the rights to use any music you upload!
- Use royalty-free music from sites like:
  - YouTube Audio Library
  - Free Music Archive
  - Incompetech
  - Bensound
- Or use your own original music
- Or get permission from the copyright holder

## Testing
After uploading, click the music toggle button (🎵) on any page to test it!
