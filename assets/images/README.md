# Images Folder

Place your photos here with the following names:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg

You can use JPG, PNG, or any image format supported by browsers.

## Recommended Image Sizes
- Width: 800-1200px
- Aspect ratio: 4:3 or 16:9 works great
- Format: JPG or PNG
- Keep file sizes under 2MB each for fast loading

## How to Add Your Photos

1. Upload your images to this folder
2. Name them photo1.jpg, photo2.jpg, etc.
3. Open `photos.html` in a text editor
4. Uncomment the image tags (remove <!-- and -->)
5. The placeholders will be replaced with your images!

Example:
```html
<!-- Before: -->
<!-- <img src="assets/images/photo1.jpg" style="width: 100%; border-radius: 10px;" alt="First Memory"> -->

<!-- After: -->
<img src="assets/images/photo1.jpg" style="width: 100%; border-radius: 10px;" alt="First Memory">
```
